Sakthi Dental Clinic Website

A modern, responsive, and user-friendly website developed for Sakthi Dental Clinic as part of an internship project. The website provides information about the clinic, dental treatments, facilities, frequently asked questions, patient testimonials, and contact/appointment enquiry options.

The project is developed using HTML, CSS, and JavaScript without any external backend or database.

📌 Project Overview

The Sakthi Dental Clinic Website is a responsive frontend website designed to provide patients with an easy way to learn about the clinic and its dental services.

The website focuses on:

Presenting the dental clinic professionally
Displaying available dental treatments
Providing information about dental care
Answering common patient questions
Displaying patient testimonials
Providing clinic contact information
Providing a contact/appointment enquiry form
Ensuring a good experience on desktop, tablet, and mobile devices
🎯 Objectives

The main objectives of this project are:

To create a professional online presence for Sakthi Dental Clinic.
To provide patients with clear information about dental treatments.
To create a responsive website that works across different screen sizes.
To provide an easy-to-use navigation system.
To improve patient engagement through FAQs and testimonials.
To provide a contact form for patient enquiries.
To demonstrate practical frontend web development skills using HTML, CSS, and JavaScript.

🌐 Website Sections
1. Header and Navigation

The website contains a navigation bar with links to:

Home
About
Treatments
FAQs
Contact

A responsive mobile navigation menu is also implemented.

2. Hero Section

The hero section introduces Sakthi Dental Clinic and highlights the clinic's dental care services.

It includes:

Main heading
Introduction
Call-to-action buttons
Clinic highlights
Dental-themed visual design
3. About Section

The About section provides information about the clinic and highlights important aspects of the dental services.

The section focuses on:

Patient care
Modern dental treatment
Professional service
Comfortable dental experience
4. Dental Treatments

The website dynamically displays dental treatments using JavaScript.

The treatments include:

Teeth Cleaning & Scaling
Tooth Filling
Tooth Extraction
Artificial Complete Denture
Dental Implants
Laser Dentistry
Root Canal Therapy
Wisdom Tooth Extraction
Fixed Partial Denture / Bridge
Teeth Whitening
Veneers
Pediatric Dentistry
Flap Surgery
Orthodontic Braces
Clear Aligners

Initially, a limited number of treatments are displayed. The Load More button allows users to view the remaining treatments.

5. Facilities

The website presents the clinic's facilities and services in a visually organized layout.

This section helps users understand the type of environment and services provided by the clinic.

6. Patient Testimonials

A testimonial slider is implemented using JavaScript.

Users can:

View different testimonials
Move to the previous testimonial
Move to the next testimonial
Automatically view rotating testimonials

The testimonial section also contains navigation indicators.

7. Frequently Asked Questions

The FAQ section provides answers to common dental questions.

Examples include:

Can medication completely relieve tooth pain?
Does teeth scaling damage enamel?
Can painful teeth be treated with fillings?
Is a crown necessary after root canal treatment?
What is the best age to get braces?
Do all wisdom teeth need to be removed?
How can good oral hygiene be maintained?

The FAQ section uses an accordion interface, allowing users to expand and collapse answers.

8. Contact Section

The contact section provides clinic contact information and an enquiry form.

The form collects:

Name
Email
Phone number
Message

JavaScript validation checks:

Required fields
Valid email format
Valid phone number format

Currently, the form is frontend-only and does not send the submitted information to a server.

9. Footer

The footer contains:

Clinic name
Navigation links
Key treatments
Location
Phone number
Email address
Social media placeholders
Copyright information
Privacy Policy placeholder

The copyright year is automatically generated using JavaScript.

🚀 How to Run the Project
Step 1: Download or Clone the Project

Download the project files to your computer.

Step 2: Open the Project Folder

Navigate to the project directory:

Sakthi-Dental-Clinic-Website/
Step 3: Open index.html

Open index.html using any modern web browser.

For example:

Google Chrome
Microsoft Edge
Mozilla Firefox

No server or database is required to run the current version.

💻 Running Using VS Code

The project can also be opened using Visual Studio Code.

Open Visual Studio Code.
Select File → Open Folder.
Select the project folder.
Open index.html.
Use the Live Server extension if available.
Open the local website in your browser.
🔧 Current Limitations

The current project is primarily a frontend implementation.

The following features are not connected to a backend:

Appointment booking
Contact form submission
Database storage
Patient registration
Online payment
Admin dashboard
Email notifications

The contact form currently performs client-side validation and displays a confirmation message. The submitted information is not stored in a database.
